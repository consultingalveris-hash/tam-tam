Installer Tam-Tam

La messagerie qui traduit vos conversations, chiffrée de bout en bout.

Sur un téléphone Android

Télécharger Tam-Tam pour Android
  1. Touchez le bouton ci-dessus. Le téléphone peut prévenir que ce type de fichier peut être dangereux : touchez Télécharger quand même.
  2. Ouvrez le fichier tam-tam.apk (dans les notifications ou le dossier Téléchargements).
  3. Si le téléphone le demande, autorisez l’installation depuis votre navigateur (Paramètres → Autoriser cette source), puis revenez en arrière.
  4. Touchez Installer, puis Ouvrir.

Ce fichier vient directement de Tam-Tam, en attendant la sortie sur le Play Store. Plus tard, pour passer à la version du Play Store, il faudra désinstaller celle-ci une fois : votre compte et vos discussions restent sur le serveur, vous les retrouverez en vous reconnectant avec votre code de sauvegarde.

Sur iPhone, ordinateur ou tout autre appareil

  1. Ouvrez web.tam-tam.africa dans Safari (iPhone) ou Chrome.
  2. Sur iPhone : touchez le bouton Partager (carré avec une flèche), puis Sur l’écran d’accueil.
  3. Sur Android ou ordinateur avec Chrome : menu ⋮ → Installer l’application (ou Ajouter à l’écran d’accueil).

L’icône Tam-Tam apparaît alors avec vos autres applications.
